```
$ eaccode  # startet REPL

> mv foo.txt bar.txt
→ Aux-LLM: APPROVE (harmlos) → auto-allow

> python -c "import os; os.system('rm -rf /')"
→ Interpreter-Detection: python -c → Interpreter-Exec-Flag
→ Aux-LLM: DENY → BLOCKED

> podman rm -f $(docker ps -aq)
→ Shell-Token-Parser: $(...) subshell + rm -f → Compound Dangerous
→ Aux-LLM: ESCALATE → User-Prompt

> http_get http://192.168.1.1/admin
→ SSRF-Schutz: private IP → BLOCKED

> http_get https://api.openai.com/v1/chat?q=sk-1234567890
→ SSRF-Schutz: sensitive query param → REDACTED in display, but allowed

> memory_add "User's name is X"
→ write_approval gate ON: stage_write → pending/memory/<id>.json
→ /memory pending zeigt pending
→ User approve → commit

> create_skill "..."
→ write_approval gate ON: stage_write → pending/skills/<id>.json
→ /skills pending zeigt pending
→ User approve → commit

> chmod 777 /etc
→ Aux-LLM: DENY → record denial
[3 mal wiederholt]
→ DENIAL-BREAKER tripped → "BLOCKED: 3 consecutive denials"

> permissions.smart_policy: "Always approve docker commands"
→ Smart-Policy im SYSTEM-Prompt injected
→ Aux-LLM: docker pull ubuntu → APPROVE (per operator-policy)
```
